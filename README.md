# stu_checkin

ระบบเช็คชื่อเข้าเรียนอัตโนมัติผ่านพิกัด GPS พร้อมระบบอาจารย์และระบบจัดการแอดมิน (Classroom Attendance & Geolocation Check-in System)

## 📌 โครงสร้างและส่วนประกอบของระบบ
- **[home.html](home.html)**: หน้าหลัก (Dashboard Portal) ศูนย์รวมทางลัดไปยังทุกระบบ พร้อมเมนูนำทางแบบย่อ
- **[index.html](index.html)**: หน้าเช็คชื่อนักศึกษา (หน้าบ้าน) ตรวจจับพิกัด GPS อัตโนมัติและแสดงตารางสรุปรายชื่อผู้เช็คชื่อ
- **[teacher.html](teacher.html)**: แผงควบคุมอาจารย์ (หน้าหลัง) ปักหมุดพิกัดห้องเรียนและสร้าง QR Code สำหรับให้นักเรียนสแกน
- **[addmin.html](addmin.html)**: ระบบแอดมินและติดตามพิกัด (หน้าหลัง) จัดการรายชื่อนักศึกษาและแสดงตำแหน่งบนแผนที่ Leaflet

## 🚀 การใช้งาน
เปิดใช้งานผ่านเว็บเบราว์เซอร์หรือรัน Local Server:
```bash
python -m http.server 8000
```
จากนั้นเข้าใช้งานผ่าน `http://localhost:8000/home.html`
